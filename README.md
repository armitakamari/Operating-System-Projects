# Operating System Projects

This repository contains two university projects completed for the **Operating Systems** course.  
Each project was implemented according to the assignment requirements, and the related project statements / specifications are also included in the repository for reference.

## Projects Included

### 1) OS-CA1 – Concurrent Intersection Traffic Simulation
A concurrent simulation of vehicles entering and crossing a multi-lane intersection safely and fairly.  
The project models vehicles, lanes, routes, and the intersection itself, and uses synchronization and scheduling mechanisms to control access.

### 2) OS Final Project – CPU Scheduling Simulator
A Java-based process scheduling simulator that models process generation, ready-queue management, CPU execution, and synchronized concurrent components.  
The project demonstrates process scheduling and coordination between generator, scheduler, and CPU modules.
